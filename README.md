Домашняя аптечка
Веб-приложение на Flask для учёта домашних лекарств с отслеживанием сроков годности, email-уведомлениями и аналитикой пользовательских сессий.
Возможности

Личная аптечка — каждый пользователь ведёт свой список лекарств с указанием срока годности.
Контроль сроков годности — препараты автоматически помечаются статусами: ok (в порядке), warning (истекает в течение 30 дней), expired (просрочено).
Справочник лекарств — автодополнение названия при добавлении препарата с подстановкой описания. Можно импортировать полный реестр из реестра ГРЛС.
Email-уведомления — отправка письма со списком просроченных и истекающих препаратов на почту пользователя.
Регистрация и авторизация — на базе Flask-Login с хешированием паролей.
Профиль пользователя — указание email, даты рождения и пола.
Аналитика сессий — для каждого пользователя: история входов, длительность сессий, просмотры страниц, количество действий, графики активности по дням и топ страниц.
Админ-панель — общая аналитика по всем пользователям с фильтрами по периоду, конкретному пользователю, полу и возрасту; демографические графики; реестр пользователей; управление правами администратора.

Технологии

Backend: Python, Flask, Flask-SQLAlchemy, Flask-Login
База данных: SQLite
Frontend: HTML-шаблоны (Jinja2)
Email: SMTP (smtplib)
Импорт данных: pandas, openpyxl
Деплой: gunicorn (Procfile)

Установка и запуск

Клонируйте репозиторий и перейдите в папку проекта:

bash   git clone <url-репозитория>
   cd Domashniya_aptechka

Создайте виртуальное окружение и установите зависимости:

bash   python -m venv venv
   source venv/bin/activate      # Windows: venv\Scripts\activate
   pip install -r requirements.txt

Запустите приложение:

bash   python app.py
По умолчанию приложение доступно на http://localhost:5000. Порт можно задать через переменную окружения PORT.
При первом запуске автоматически создаётся база данных, наполняется тестовый справочник из 5 препаратов, а первый зарегистрированный пользователь становится администратором.
Импорт справочника лекарств
Для загрузки полного реестра лекарств из файла ГРЛС (Excel) или CSV:
bashpython import_data.py
По умолчанию скрипт ожидает файл grls2026-02-10-1-Действующий.xlsx в корне проекта (название можно изменить в конце import_data.py). Для Excel-файла ГРЛС используется столбец 8 (название препарата) и столбец 13 (фармакологическая группа).
Настройка email
Параметры SMTP задаются в app.py:
pythonapp.config['MAIL_SERVER']   = 'smtp.gmail.com'
app.config['MAIL_PORT']     = 587
app.config['MAIL_USERNAME'] = 'ваш_адрес@gmail.com'
app.config['MAIL_PASSWORD'] = 'пароль_приложения'
app.config['MAIL_FROM']     = 'ваш_адрес@gmail.com'
Для Gmail используйте пароль приложения, а не основной пароль аккаунта.

Безопасность: в текущей версии SECRET_KEY и учётные данные почты захардкожены в app.py. Перед публичным развёртыванием вынесите их в переменные окружения (.env) и смените значения.

Роли пользователей

Пользователь — управляет своей аптечкой, профилем и видит собственную аналитику (/analytics).
Администратор — дополнительно имеет доступ к общей аналитике (/admin/analytics) и может назначать/снимать права администратора другим пользователям.
