ДОМАШНЯЯ АПТЕЧКА
Веб-приложение на Flask для учёта домашних лекарств с отслеживанием сроков годности, email-уведомлениями и аналитикой пользовательских сессий.


ВОЗМОЖНОСТИ
- Личная аптечка — каждый пользователь ведёт свой список лекарств с указанием срока годности.
- Контроль сроков годности — препараты автоматически помечаются статусами: ok (в порядке), warning (истекает в течение 30 дней), expired (просрочено).
- Справочник лекарств — автодополнение названия при добавлении препарата с подстановкой описания. Можно импортировать полный реестр ГРЛС.
- Email-уведомления — отправка письма со списком просроченных и истекающих препаратов на почту пользователя.
- Регистрация и авторизация — на базе Flask-Login с хешированием паролей.
- Профиль пользователя — указание email, даты рождения и пола.
- Аналитика сессий — для каждого пользователя: история входов, длительность сессий, просмотры страниц, количество действий, графики активности по дням и топ страниц.
- Админ-панель — общая аналитика по всем пользователям с фильтрами по периоду, пользователю, полу и возрасту; демографические графики; реестр пользователей; управление правами администратора.


ТЕХНОЛОГИИ
- Backend: Python, Flask, Flask-SQLAlchemy, Flask-Login
- База данных: SQLite
- Frontend: HTML-шаблоны (Jinja2)
- Email: Flask-Mail (SMTP)
- Импорт данных: pandas, openpyxl
- Конфигурация: python-dotenv (переменные окружения)
- Деплой: gunicorn (Procfile)

УСТАНОВКА И ЗАПУСК
1. Клонируйте репозиторий и перейдите в папку проекта:
   git clone https://github.com/timurcybin-web/Domashniya_aptechka.git
   cd Domashniya_aptechka

2. Создайте виртуальное окружение и установите зависимости:
   python -m venv venv
   source venv/bin/activate      (Windows: venv\Scripts\activate)
   pip install -r requirements.txt

3. Создайте файл .env на основе шаблона и заполните своими значениями (см. раздел «Настройка окружения»):
   cp .env.example .env

4. Запустите приложение:
   python app.py

Приложение будет доступно на http://localhost:5000. Порт можно задать через переменную окружения PORT.
При первом запуске автоматически создаётся база данных, наполняется тестовый справочник из 5 препаратов, а первый зарегистрированный пользователь становится администратором.


НАСТРОЙКА ОКРУЖЕНИЯ
Все секреты и параметры хранятся в файле .env (в репозиторий он не коммитится). Скопируйте .env.example в .env и заполните:

SECRET_KEY — случайная строка для подписи сессий Flask.
  Сгенерировать: python -c "import secrets; print(secrets.token_hex(32))"
DATABASE_URL — подключение к БД (по умолчанию sqlite:///meds.db)
MAIL_SERVER — smtp.gmail.com
MAIL_PORT — 587
MAIL_USERNAME — your_address@gmail.com
MAIL_PASSWORD — пароль приложения (не основной пароль аккаунта!)
MAIL_FROM — your_address@gmail.com

Для Gmail включите двухэтапную аутентификацию и создайте отдельный пароль приложения — основной пароль аккаунта использовать нельзя.


ИМПОРТ СПРАВОЧНИКА ЛЕКАРСТВ

Для загрузки полного реестра лекарств из файла ГРЛС (Excel) или CSV:
   python import_data.py

По умолчанию скрипт ожидает файл grls2026-02-10-1-Действующий.xlsx в корне проекта (название можно изменить в конце import_data.py). Для Excel-файла ГРЛС используются столбец 8 (название препарата) и столбец 13 (фармакологическая группа).


РОЛИ ПОЛЬЗОВАТЕЛЕЙ
- Пользователь — управляет своей аптечкой, профилем и видит собственную аналитику (/analytics).
- Администратор — дополнительно имеет доступ к общей аналитике (/admin/analytics) и может назначать/снимать права администратора другим пользователям.
